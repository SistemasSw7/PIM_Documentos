# Sistema de Agendamentos Barbearia Santos

Este repositório tem como objetivo mostrar o processo de criação do sistema de agendamentos da Barbearia Santos.

O projeto está dividido em etapas, sendo cada etapa organizada em um diretório específico.

## Diretórios

1. [Backlog produto](./Backlog_produto/)
2. [Sprint Planning](./Sprints/)
3. [Diagramas UML](./Diagramas/)
4. [Diagramas BD](./Banco_Dados/)

## Objetivos de cada diretório.

1. Documentar o Backlog do produto.
2. Documentar o planejamento de cada sprint junto de suas tarefas e metas.
3. Documentar os diagramas da UML
4. Documentar os diagramas de Banco de dados.

## Ferramentas e Tecnologias

- GITHUB
- C
- ARQUIVOS BINÁRIOS
- BR-MODELO
- ASTAH UML

## Observação

Este repositório tem a finalidade de documentar o progresso do projeto do PIM-2.
