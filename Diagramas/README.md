# DIAGRAMAS UML.

## Diagramas De Caso De Uso.

Os diagramas de caso de uso foram feitos com base no que o sistema deve fazer de forma geral, sendo os casos de uso tanto na imagem quanto casos de uso descritivos

## Diagramas De Classe (Etendido a Linguagem Estruturada)

No diagramas de classe que foi estendido para trabalharmos com C, utilizamos a rotina que cada usuário terá dentro do sistema para documentar as ações dentro do sistema como funções
