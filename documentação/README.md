# Documentação Barbearia Santos

## Resumo da documentação

Esta documentação técnica constitui o registro formal do Projeto Integrado Multidisciplinar (PIM II), desenvolvido como requisito parcial para o curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas da Universidade Paulista (UNIP). O documento tem como finalidade consolidar, estruturar e evidenciar a aplicação prática dos conceitos teóricos ministrados ao longo do semestre, integrando disciplinas de Engenharia de Software, Linguagem de Programação, Estrutura de Dados, Modelagem de Banco de Dados e Infraestrutura.

A elaboração deste documento foi conduzida segundo uma metodologia de documentação contínua e alinhada ao ciclo de vida de desenvolvimento ágil do software. A estrutura do relatório foi concebida para mapear gradualmente todas as etapas da engenharia do sistema idealizado para a Barbearia Santos:

|Elicitação e Especificação| |Mapeamento das necessidades do negócio, identificação dos perfis de acesso e especificação formal dos Requisitos Funcionais (RF) e Não Funcionais (RNF)|

Modelagem e Arquitetura: Representação gráfica dos fluxos de processos por meio de diagramas UML (Casos de Uso e Diagramas de Classes) e modelagem de dados relacional via Modelo Entidade-Relacionamento (MER).

Detalhamento de Implementação: Descrição da lógica computacional desenvolvida em linguagem C, destacando a arquitetura modular em arquivos de cabeçalho (.h) e implementação (.c), as validações de dados e a estratégia de persistência binária em disco (.dat).

Acompanhamento das Entregas: Registro do progresso das Sprints do projeto, relacionando os artefatos construídos às etapas planejadas no Product Backlog.

Dessa forma, esta documentação serve como instrumento de validação acadêmica e guia de referência técnica, demonstrando a rastreabilidade entre as necessidades do cliente, o planejamento ágil e a entrega efetiva da solução de software.
